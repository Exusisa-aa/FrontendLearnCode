静态定位static

  • 没有边偏移属性
  • 标准流盒子默认为静态定位，相当于无定位

相对定位relative

  • 相对于原来自己的位置移动
  • 原来的位置仍然有它本身，如标准流一般占有一定空间，不会脱标
  • 主要作用是限制绝对定位

绝对定位absolute

  • 如果没有祖先元素或祖先元素没有定位，则是相对于网页移动的
  • 如果祖先元素有定位（相对，绝对，规定定位），则以最近一级的有定位的祖先元素为参考点移动位置
  • 绝对定位不再占有原先的位置

子绝父相

  • 子级用绝对定位，父级用相对定位
  • 子级用绝对定位不会占有盒子，可以放到父盒子里的任何一个地方，不影响其他兄弟
  • 父盒子需要加定位限制子盒子在父盒子内显示
  • 父盒子布局时，需要占有位置，因此父级用相对定位

固定定位fixed

  • 以浏览器可视窗口为参照点而移动元素
  • 不随滚动条滚动而滚动，跟父元素无关
  • 脱标的，不占有原来的位置
  • 必须设置位置

让固定定位始终贴着版心

  • 设置为left:50%
  • 设置为margin-left:版心一半的距离

粘性定位sticky

  • 以浏览器的可视化窗口为参照点
  • 不脱标占有原先的位置
  • 必须添加位置的其中一个才有效
  • 位置的意义是当距离边多少时就开始随页面的滚动而暂停

定位的叠放顺序z-index

  • 默认是auto，数值越大，盒子越往上
  • 如果属性相同，按照后来者居上的原则
  • 数字后面不接单位
  • 只有定位的盒子才有z-index的属性

绝对定位盒子的居中显示

  • 加50%只让边居中
  • 加负值让盒子往相对面走

定位的特性

内容大小
  • 当行内元素添加绝对定位后，可直接设置高度与宽度
  • 当块级元素添加绝对定位后，其默认大小变为内容大小
  • 浮动元素和定位元素不触发外边距合并
