display显示与隐藏

  • display隐藏后不再占有原来的位置
  • 后期搭配js可以做出许多互动
  • none是隐藏，block是显示

visibility显示与隐藏

  • visibility隐藏后继续占有原来的位置
  • hidden是隐藏，visible是显示
